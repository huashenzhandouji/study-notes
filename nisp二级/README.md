## 一、基础与攻击篇

### 1. 典型网络攻击
| 攻击类型 | 核心原理 | 备注 |
|:---|:---|:---|
| **IP欺骗** | 伪造源IP，常用于DoS或绕过IP信任 | 常与SYN Flood结合 |
| **ARP欺骗** | 无状态协议，发送伪造ARP Reply污染缓存 | 局域网MITM |
| **DNS欺骗** | 污染DNS缓存，返回错误IP | 配合钓鱼 |
| **DoS** | 消耗资源（带宽/CPU/连接） | 致服务不可用 |
| **DDoS** | 控制Botnet分布式攻击 | 流量大，难防御 |
| **SYN Flood** | 发大量SYN，耗光半开连接队列 | 最常见 |
| **Teardrop** | 构造错误IP分片偏移 | 老系统崩溃 |

### 2. 恶意代码
- **类型**：病毒、蠕虫、木马、逻辑炸弹、流氓软件
- **清除**：引导区修复、文件替换、内存清理、补丁更新

## 二、防护技术篇

### 1. 访问控制模型
| 模型 | 核心机制 | 特点 |
|:---|:---|:---|
| **DAC 自主** | 基于ACL或Capability | 灵活但防不住木马 |
| **MAC 强制** | 主/客体打安全标签 | 军事级，不可改 |
| **RBAC 角色** | 用户→角色→权限 | 便于管理 |
| **BLP** | 上写下读 | 保机密性 |
| **BiBa** | 上读下写 | 保完整性 |

### 2. 防火墙与WAF
- **防火墙**：静态包过滤、应用代理、状态检测
- **WAF**：防SQL注入、XSS、Web访问控制

### 3. 密码学基础
| 类别 | 算法 | 作用 |
|:---|:---|:---|
| **对称** | AES, DES | 加密速度快 |
| **非对称** | RSA, SM2 | 密钥交换、签名 |
| **哈希** | SHA-256 | 完整性校验 |
| **MAC** | HMAC | 完整性+真实性 |

### 4. 身份鉴别 (AAA)
| 协议 | 传输 | 特点 |
|:---|:---|:---|
| **RADIUS** | UDP 1812/1813 | 仅加密密码 |
| **TACACS+** | TCP 49 | 全包加密，命令级授权 |
| **Diameter** | TCP/SCTP | 下一代，高可靠 |

### 5. Kerberos
- **过程**：AS发TGT → TGS发Ticket → 访问服务
- **缺陷**：依赖时间同步，KDC单点故障风险

## 五、评估、审计与管理体系篇

### 1. 风险评估
- **公式**：`R = f( 威胁频率, 资产价值 × 脆弱性 )`
- **标准**：GB/T 20984、ISO 27005

### 2. 信息系统审计
- **流程**：计划 → 现场 → 发现 → 方案 → 报告 → 跟踪
- **技术**：渗透测试、日志分析
- **管理**：账户管理、备份恢复

### 3. 业务连续性与灾备 (BCM/DRP)
- **指标**：RTO（恢复时间）、RPO（恢复点）
- **灾备等级**：国标 1~6 级
- **RAID**：0（条带）、1（镜像）、5（校验）、10（镜像+条带）

### 4. ISMS (ISO 27001)
- **PDCA循环**：
  - **Plan**：方针、目标、风险评估
  - **Do**：实施控制措施
  - **Check**：监控、审计
  - **Act**：持续改进

### 5. ISO 27002 十四大控制域
> **口诀：策组人资访密物，操通开供事业合**

1. 信息安全策略
2. 信息安全组织
3. 人力资源安全
4. 资产管理
5. 访问控制
6. 密码学
7. 物理与环境安全
8. 操作安全
9. 通信安全
10. 系统开发维护
11. 供应商关系
12. 事件管理
13. 业务连续性
14. 符合性

## 六、终极逻辑闭环 🎯

> **首先**识别资产、威胁与脆弱性（**评估**）  
> ↓  
> **通过**风险评估制定策略（**风险管理**）  
> ↓  
> **利用**技术（防火墙/加密/访问控制）与管理（ISMS/PDCA）处置风险  
> ↓  
> **借助**审计验证措施有效性（**审计**）  
> ↓  
> **最后**通过BCP/DRP确保业务不中断（**持续改进**）
